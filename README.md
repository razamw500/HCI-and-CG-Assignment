# HCI & CG Assignment — LaTeX Version

This repository contains the assignment PDF and the complete LaTeX source.

## Files

- `main.tex` — main LaTeX source file.
- `Image22.jpg` — image used on the HCI page.
- `Image30.jpg` — image used on the Computer Graphics page.
- `HCI & CG Assignment.pdf` — submitted PDF.

## Compile on Overleaf

1. Create a new blank project on Overleaf.
2. Upload `main.tex`, `Image22.jpg`, and `Image30.jpg`.
3. Set `main.tex` as the main document if Overleaf does not select it automatically.
4. Click **Recompile**.

The image filenames in `main.tex` exactly match the uploaded image files, so the images will appear when the project is compiled.

## Local compilation

The document uses standard LaTeX packages available on Overleaf and can be compiled with `pdflatex main.tex`.
